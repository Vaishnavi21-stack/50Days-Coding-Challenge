This project analyzes student performance data using Python with a list of dictionaries as the dataset. User-defined functions are implemented to calculate averages, identify top-performing students, and detect at-risk students based on performance metrics. The data is grouped by batches (b7, b8, b9) using loops and dictionary structures. Batch-level summaries such as average attendance, assignment submission, and content consumption are computed. A comparison mechanism is used to determine the best-performing batch overall. The solution demonstrates the use of core Python concepts including functions, loops, conditions, and data aggregation. This project reflects a basic data analysis workflow without relying on external libraries like pandas.
