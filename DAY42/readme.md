The Survey Feedback Analyzer is a beginner-friendly Python project developed to analyze customer survey feedback using basic Data Science and Python programming concepts. The project stores feedback data in a dictionary of lists, allows users to add new feedback entries, and performs text cleaning operations such as removing punctuation, converting text to lowercase, and removing extra spaces.

The project also includes feedback analysis features like counting specific words, calculating average ratings, identifying the longest feedback comment, extracting unique words, and sorting feedbacks based on ratings. Through this project, important Python concepts such as loops, conditional statements, functions, string manipulation, lists, dictionaries, and data processing techniques are applied in a practical way.

Overall, this project helps beginners understand how Python can be used for simple text analysis and customer feedback management in real-world applications.
