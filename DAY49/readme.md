This project focuses on analyzing cyberbullying and toxic online comments using Python in Google Colab. The dataset was cleaned by removing duplicate records, handling null values, and cleaning special characters from text comments. A toxic label was created to identify aggressive comments in the dataset. Exploratory Data Analysis (EDA) was performed to understand toxicity patterns across different categories.

Word cloud visualization and bar charts were created to identify commonly used toxic words. Platform-wise analysis was performed to determine which social media platform had the highest toxic activity. Age group and gender-based analysis were also conducted to study the impact of cyberbullying among users. Time-based toxicity trends and heatmaps were generated to identify peak toxic activity hours.

Several KPI metrics such as Toxic Comment Percentage, High-Risk User Count, Most Harmful Platform, Peak Toxic Hours, and Cyberbullying Frequency were calculated. The project highlights how cyberbullying negatively affects online communities and emphasizes the importance of AI-based moderation systems and safer online practices. This analysis can help social media platforms improve community moderation and create safer digital environments.
