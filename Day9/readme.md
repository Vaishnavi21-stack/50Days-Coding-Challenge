# Eating Out vs Health Dashboard (Power BI Project)

## Project Overview
This project analyzes the relationship between eating out habits and health conditions using Power BI.  
The dashboard shows how lifestyle factors like eating frequency, exercise, sleep, and calories affect health score, BMI, cholesterol, and blood pressure.

## Dataset
The dataset contains information about:
- Age
- Gender
- Occupation
- Eat_Out_Frequency
- Preferred_EatOut_Type
- Daily_Calories
- Exercise_Hours_Per_Week
- Sleep_Hours
- BMI
- Cholesterol_Level
- BloodPressure
- Health_Score

## Tools Used
- Power BI
- DAX Measures
- Conditional Formatting
- GitHub

## Dashboard Pages

### Page 1 – Overview
Shows KPI cards and high-level insights:
- Average Health Score
- Average Eat Out Frequency
- BMI Analysis
- Cholesterol Analysis

### Page 2 – Eating Out vs Health Trends
Shows relationship between eating habits and health:
- Scatter plot (Calories vs Health Score)
- Pie chart (Eating type distribution)
- Table with conditional formatting

### Page 3 – Demographics & Lifestyle Insights
Shows how people characteristics affect health:
- Age vs Health Score
- Gender vs BMI
- Exercise vs Health Score
- Sleep vs Health Score

## Key Insights
- Higher eating out frequency is linked with higher BMI and cholesterol.
- More exercise hours improve health score.
- Less sleep may reduce health score.
- Healthy food preference shows better overall health.
