# Social Media Data Analysis using SQL

This project focuses on analyzing a social media database using SQL.
The database includes tables such as Users, Posts, Likes, Comments, and Friendships.

Various SQL concepts like JOINs, GROUP BY, subqueries, and aggregate functions were used to extract insights from the data.
Tasks included retrieving posts with user details, analyzing comments, and identifying user activity patterns.

A stored procedure was implemented to calculate user engagement metrics such as total posts, likes, and comments.
Advanced queries were written to identify top users and analyze engagement trends.

The final challenge involved finding the most influential user based on total likes and comments received.

This project helped strengthen practical SQL skills and understanding of relational database concepts.
