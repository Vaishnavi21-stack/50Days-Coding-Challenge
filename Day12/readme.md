🔹 Overview

This project analyzes the performance of the MGNREGS scheme across different states and years using Power BI. The objective is to identify trends, compare state-level performance, and derive actionable insights.
🔹 Dataset

The dataset includes:

Year
State
Households Demanded
Households Provided
Person-Days Generated
Expenditure (in Crores)
🔹 Data Preparation
Cleaned and preprocessed data using Power Query
Handled missing values and ensured correct data types
Removed duplicates
Built calculated measures such as:
Work Completion Rate
Demand-Supply Gap
Expenditure per Person-Day
🔹 Dashboard Features

📈 Overview Dashboard
Trend analysis of person-days generated over years
KPI cards for total expenditure, person-days, and completion rate
Interactive slicers for Year and State
📊 Comparative Analysis
Top and bottom performing states (Work Completion Rate)
State-wise comparison using bar charts
Drill-down analysis
Geographic visualization using map

🔹 Key Insights
Person-days generated show an increasing trend over the years
Significant variation exists in performance across states
Some states consistently achieve higher work completion rates
Underperforming states require policy attention

🔹 Recommendations
Improve monitoring in underperforming states
Ensure timely work allocation and wage payments
Replicate best practices from top-performing states
Include additional socio-economic data for deeper analysis

🔹 Tools Used
Power BI
Excel
Conclusion

This project demonstrates how data visualization can help in evaluating government schemes and supporting data-driven decision-making.
