## 📌 Assignment Summary

In this assignment, I worked on different data structures in Python including strings, lists, tuples, and dictionaries.

I solved problems to improve my understanding of how each data structure works:

* In the **string problem**, I found the length of the longest substring without repeating characters.
* In the **list problem**, I removed duplicate elements while keeping the original order.
* In the **tuple problem**, I identified the maximum and minimum values from a given tuple.
* In the **dictionary problems**, I counted the frequency of characters in a string and grouped words based on their length.

Through this assignment, I practiced writing simple and logical Python programs using loops, conditions, and built-in functions.

This helped me understand how to organize data and apply problem-solving techniques using different data structures in Python.
