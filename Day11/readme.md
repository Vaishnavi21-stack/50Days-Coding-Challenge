# Insurance Claim Incident Analysis - Power BI Project

## Project Overview
This project analyzes an insurance claims dataset using Power BI to identify trends in claims, fraud cases, customer segments, and policy details.  
The goal is to build interactive dashboards and generate insights that help an insurance company understand risk patterns and claim behavior.

## Problem Statement
Analyze and visualize the insurance claims data to answer key business questions:
- What are the trends in claims by state, incident type, and time?
- Which customer segments have the highest claim amounts?
- What is the distribution of fraudulent vs non-fraudulent claims?
- What is the relationship between policy premium, deductible, and claim amount?

## Tools Used
- Power BI
- Excel
- Power Query
- DAX (basic)

## Dataset Features
The dataset includes:
- Policy details (state, premium, deductible, limit)
- Customer details (age, gender, education, occupation)
- Incident details (type, date, severity, location)
- Claim details (total claim, injury, property, vehicle)
- Fraud reported status

## Deliverables
- Imported and cleaned dataset in Power BI
- Created multiple visualizations (bar charts, pie chart, line chart, scatter, table, cards)
- Claim analysis by state, incident type, and time
- Customer segmentation by age, gender, education, occupation
- Fraud vs non-fraud analysis
- Interactive slicer for filtering
- Summary of insights

## Key Insights
- Highest claim amounts observed in certain states
- Multi-vehicle collisions produce higher claim values
- Fraud cases exist but are fewer than non-fraud cases
- Some age groups and occupations show higher claims
- Higher premium policies tend to have higher claim amounts
