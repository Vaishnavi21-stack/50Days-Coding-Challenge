# Summary

This assignment focuses on building a structured Python program using user-defined functions to process and analyze student marks.

The program is designed to take input for three subjects, store the values in a list, and perform calculations in a modular way. Separate functions are used to compute the total and average marks, ensuring clarity and proper code organization.

Based on the calculated average, a grading system is implemented using conditional statements to classify performance into different categories.

The main program integrates all the functions and displays the final results, including total marks, average, and grade.

Overall, this assignment demonstrates the use of functions, lists, and decision-making statements, while emphasizing clean and organized programming practices.
