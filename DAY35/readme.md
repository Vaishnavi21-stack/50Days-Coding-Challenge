# 🧠 Python Coding Challenges – Solutions

## 📌 Overview

This repository contains solutions to a set of foundational Python coding challenges.
The goal of this assignment was to strengthen core programming concepts and write clean, efficient, and readable code.

Each problem focuses on a specific Python concept such as list comprehension, dictionary handling, sets, and string manipulation.

---

## 🚀 Challenges Covered

### 1. Flatten a Nested List

* **Concept:** List Comprehension
* **Approach:** Used nested iteration within a list comprehension to extract elements from sublists into a single list.

---

### 2. Check Anagram

* **Concept:** `sorted()`
* **Approach:** Compared sorted versions of both strings after normalizing case and removing spaces.

---

### 3. Find Missing Number

* **Concept:** `set()`
* **Approach:** Generated a complete range of numbers and used set difference to identify the missing value.

---

### 4. Group Words by First Letter

* **Concept:** Dictionary, `setdefault()`
* **Approach:** Grouped words dynamically by their first character using dictionary methods.

---

### 5. Remove Empty Values

* **Concept:** Dictionary Comprehension
* **Approach:** Filtered out key-value pairs where the value is `None`.
