

# Key Findings

* Users with low engagement are more likely to churn.
* Certain subscription plans show higher churn rates.
* Genre preferences influence user retention.
* Higher watch time improves retention.

# Recommendations

* Improve personalized recommendations.
* Target low-engagement users with offers.
* Promote high-retention genres.
* Improve experience for basic subscription users.

# Conclusion

This analysis identified engagement and content preferences as major drivers of subscriber churn. Increasing watch time and improving personalization can help reduce cancellations and improve customer retention.
