This project focuses on analyzing machine error data to understand the major causes of production inefficiency in a manufacturing company. The dataset contains machine IDs, error types, and timestamps that help identify recurring operational issues. Data cleaning techniques such as handling missing values, removing duplicates, and converting datetime formats were performed to prepare the dataset for analysis. Exploratory Data Analysis (EDA) was used to identify machines with the highest number of errors and the most frequent error types. Trend analysis showed how machine errors changed over time and highlighted periods with increased operational issues. Heatmaps and bar charts were created to visualize machine failure patterns and error distributions. The analysis revealed that certain machines repeatedly generated errors, indicating the need for preventive maintenance. Frequent machine errors can lead to downtime, production delays, and increased maintenance costs. The project also highlights the importance of continuous monitoring and predictive maintenance in manufacturing industries. Based on the findings, recommendations such as regular machine inspections, early fault detection, and maintenance scheduling were suggested to improve production efficiency and reduce downtime.
